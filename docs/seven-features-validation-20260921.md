# 2026-09-21 使用体验与公告验收

本轮实现数学渲染、公告、新人引导、账号菜单、Fermata 日志、分角色使用文档、投稿模板及评价 Markdown。

## 关键修正

- 上下标异常根因是渲染器依赖 KaTeX 0.16.47、页面样式依赖 0.18.1，现将直接依赖锁定为 0.16.47；测试核对两者版本一致。
- 支持 `\(...\)` 与 `\[...\]`；已有公式、代码块、行内代码、链接目标等保护范围不改写。分式、上下标、求和与多行排版有单元与浏览器尺寸验证。
- 公告管理为独立 `announcement.manage`，默认受众新人，可指定天数、全体或权限组；草稿、发布、撤回、置顶、版本已读与未读弹窗均服务端保存。角色撤销/过期不再接收，事务重验权限并与审计一起提交。
- `/guide` 按投稿人、成员、组长、管理员递增，正文包含基础/正式内容差异、投稿审核与组题交付、权限、插件和备份。正文链接可用于公告。
- 投稿模板先解析预览再填表，保留各内容区和样例；未知/重复分区、多题、不成对样例均拒绝，不静默丢内容，不绕过创建权限。
- 审题改进点、公开评论与内部备注可编辑/预览 Markdown；公开与私密边界保持。
- 头像菜单外部点击、焦点离开、Escape、浏览器失焦和路由切换自动关闭。
- Fermata 通过独立管理 HTTP 提供受限日志，Urmotiv 只作鉴权代理。日志页有筛选和可选刷新，不返回文件、秘密、题目身份或模型原文。
