# 附件删除与标准程序编辑

附件列表补上带确认的「×」删除。删除创建新题目修订，只移除当前版本关联，旧版本和已固定的比赛资料不变；已绑定的评测程序一并解除绑定。图片和测试数据删除后仍需用户检查正文引用和数据点路径。

新建题目及「题解与资料」均有标准程序源码编辑框、语言选择和高亮预览；已导入文件直接读取到编辑框。界面不再要求先准备文件，存储仍复用标准程序附件类别，保证原有导入导出与历史修订兼容。修改源码和切换语言时原子替换指定文件，不修改旧版本；未知编码或过大的旧文件提示下载检查。

真人作者可读写自己题目的源码，写入要求编辑权；内部资料读写的明确拒绝优先。此能力不开放测试数据或内部附件。非作者和机器人继续遵循原测试数据权限。按路径替换也禁止跨类别，防止内部文件被改成公开附件。

AI 仍只提取原文行号，std 独立保存，围栏仅用于识别语言和取出代码。未分类材料留在正式题解供整理。若草稿已创建但源码保存失败，保留草稿编号，重试不会重复建题；此流程不是将创建题目和上传对象假装成跨服务原子事务。
