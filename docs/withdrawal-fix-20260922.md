# 投稿撤回修复

此前只有待审和通过状态能撤回，不通过状态被排除；个人列表也没有撤回入口。现在作者保留本题编辑权限时，可以从「我的投稿」或总列表的本题状态栏点击「撤回为草稿」，也可以在题目工作区执行。待审、通过、不通过均支持。

撤回保留既有审核意见与最终决定，不会删除历史。再次提交进入新轮次。服务端仍检查本人所有权或状态管理权限、题目可见性、当前修订，非本人越权和旧修订请求被拒绝。
