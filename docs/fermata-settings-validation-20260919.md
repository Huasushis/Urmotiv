- API 管理路由：15 项通过；覆盖无权访问、机器人拒绝、写入模型/连接/密钥、密钥不回显、版本冲突 409 和上游安全错误。
- `@urmotiv/plugin-fermata-control` 客户端：4 项通过，兼容省略新增字段的旧服务响应。
- Web 全量：24 文件 154 项通过。API 构建、Web 类型检查与构建通过。

生产升级先更新此客户端，再更新 Fermata 服务；这样严格旧响应解析器不会先收到新版字段。上线与重启持久化检查另记在部署交接中。
