# Urmotiv 产品规格（当前实现）

本文是当前仓库的公开产品边界，不是开发任务清单。接口字段以 `@urmotiv/contracts` 的运行时模式为准；页面按钮不是授权依据。

## 产品定位

Urmotiv 管理竞赛题目的协作生命周期：草稿、题面和题解编辑、附件与评测配置、提交审核、审核意见、组题固定、题目包导入导出和权限审计。它不编译或执行参赛者代码，不是评测机，也不提供沙箱。

## 核心工作流

- 题目必须至少绑定一个、最多三十个当前启用知识点；类型为 `traditional`、`interactive` 或 `submit_answer`。
- 草稿可以由有权用户继续编辑；提交后进入 `pending_review`，基础题面和基础题解冻结。紧急修改使用专用冻结字段接口并填写原因。
- 审核意见绑定题目修订和当前轮次；旧轮次、已关闭轮次、无权人员和摘要不一致的意见不能写入。
- 审核规则可按通过/不通过人数和审核条目计算 `pending`、`approve` 或 `reject`；最终状态由核心服务和 `problem.status.change` 权限执行。
- 比赛方案只能加入已通过题目；锁定后固定题目修订、成员和分值，之后不能替换内容，只能归档。
- 导入和导出使用预览 → 确认 → 异步任务流程；任务固定格式插件版本、题目修订、文件类别和权限快照，并在 Worker 读取时再次检查。

## 认证和账号

邮箱登录默认开启，邮箱注册默认关闭；USTC OAuth、CAS、演示登录均需显式配置。OAuth 状态绑定发起浏览器并在十分钟内一次性消费；身份键是“提供方 + 稳定编号”。全新部署必须由真实服务器 TTY 运行管理员 bootstrap；没有人工管理员时 API 业务入口保持阻塞。遗失管理员密码只能在真实 TTY 运行恢复，恢复会撤销该管理员现有会话。

## 权限和隐私

权限记录包含允许/拒绝、作用域、到期时间、授权者和原因。账号停用、登录权限、机器人固定禁用、对象范围、明确拒绝和允许按固定顺序计算；任何匹配的明确拒绝优先。无权知道资源存在时，题目、文件、任务和插件管理接口统一按 `404 Not Found` 返回，不通过列表、数量、文件名或错误差异泄露资源。

题面图片、附件、测试数据、标准程序和评测程序都通过题目/文件权限访问；对象存储位置不是下载凭据。密码、令牌、OAuth 授权码、外部服务密钥、内部题面和原始上游响应不得进入日志、审计、导出包或错误响应。

## 插件与外部服务边界

插件宿主只加载编译进服务端的受信任内置代码，插件不能动态增加核心权限、读取数据库或跨插件密钥。支持提交前检查、审核条目、审核决策规则和题目包格式适配器；检查超时和失败行为按插件设置处理，明确阻止不可由客户端重试抵消。

Anklang 只做私有边界内的仅检索结果原题相似性检索和受控索引同步，支持实时添加后查询并返回候选参考；它不是 Urmotiv 的流程、审核状态、权限或最终裁决权威。题目的查重/检查信息属于 Urmotiv 问题属性，插件可以添加，Fermata 可以读取。查询会丢弃 `recommendation`、`sameProblemSuggestion`、`explanation` 等判断字段，候选不会阻止提交；`failureBehavior` 只处理无法取得配置检查。同步仅注入 `ProblemService`，成功 submit、`pending_review`/`approved` 标题变化和冻结 `basicStatement` 变化调用冻结 `PUT /api/v1/index/problems`，失败不回滚本地修改。

## 约束和当前上限

- 单个 Markdown 字段最多 500,000 个字符；样例最多 50 个。
- API 单次文件请求体最多 512 MiB；题目包解析器默认原始包/解压总量/单文件均不超过 128 MiB，最多 10,000 个条目；默认 Web nginx 请求体上限为 128 MiB。
- 头像只接受 JPEG、PNG、WebP，最多 512 KiB；题面图片只接受 PNG、JPEG、GIF、WebP。
- 题目评测时间最多 600,000 毫秒，内存最多 262,144 MiB；题目包和评测程序不在 Urmotiv 中执行。
- 当前传输格式插件是 Hydro ZIP 与 FPS XML；导入/导出是否可用取决于对应插件已启用。
