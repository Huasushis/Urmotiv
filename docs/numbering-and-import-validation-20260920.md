# 题号修正与新题导入验收

正式题号与原表错位，不能通过网页排序修复。本次依据旧导入候选、原文件摘要和来源分组核对映射，在生产备份的独立 PostgreSQL 副本上先执行回滚演练，再提交验证。

题号迁移已在生产提交：缺失材料占位恢复 49、51、52，活跃题号为 1–156。三份旧重复导入软删除保留，原题面、版本和附件没有丢弃；已删除的测试记录移出 157、158。18 个外键约束只在事务内延迟，提交前全部验证并恢复原设置；六类关联表除编号外的内容摘要保持一致，包含审核、题目版本、访问记录、比赛和导出关系。

审计表保持只能追加的约束，原记录不改写，另记录旧号与新号的对应关系。迁移前的登录已失效，避免旧页面按旧编号提交编辑；用户名和密码不变。历史题的外部 AI 审题开启数仍为 0。

新增两份资料分别是 Markdown/图片/程序与 PDF/程序。整理时保留原始题面、题解、图片和程序，不补造测试数据、难度或知识点；没有明确分类的内容暂标“待分类”。原包与标准包的往返验证逐文件比较字节。两份 PDF 可提取文字，原 PDF 同时保留供核对排版。

同时修复网页的导入图片预览：相对路径只能解析为当前题目的已授权题面图片，不请求外部 URL，不按同名文件猜测路径。Markdown 19 项、Web 全量 155 项及类型/构建通过；桌面手机通过真实附件上传、相对路径图片加载、附件列表失败时不显示图片与无横向溢出检查。

生产新增两题的最终编号、待审状态和附件检查完成后补充结果。本报告不把尚未完成的导入计为验收通过。
