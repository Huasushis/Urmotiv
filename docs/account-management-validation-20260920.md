# 账号删除与权限管理验收

权限管理权不再被管理员当前的业务权限截断。允许维护自己所在权限组、给自己或他人增减业务权限；仍不能转授固定 root 身份。明确拒绝在实际操作时保持优先，机器人固定禁止项保留，角色事务提交前重新检查操作者是否仍有管理权限。

普通账号删除通过正式 API 执行。题目和比赛归属转给当前管理员，历史版本、审核意见和审计原样保留；目标账号退出登录、从目录移除，内部记录作为历史引用保留。自身、root、机器人及模拟登录调用被拒绝；内容上的明确拒绝或审计失败不会留下部分删除。

- API 5 文件 35 项通过，包括账号删除/回滚/权限反例、初始化后只保留 root、完整 root 权限与账号切换边界。
- 真实 PostgreSQL 4 项通过，包括撤销权限管理授权与角色提交之间的并发检查。
- 数据库首次初始化 9 项通过。发现旧代码把迁移数量固定为 28，新增合法迁移后会拒绝新安装；现改为读取正式迁移清单，保留数据库内容与初始化状态检查。
- Web 全量 155 项通过；桌面和手机均验证删除前确认、取消保持账号、确认后目录移除、题目归属转移及旧登录失效，截图已生成。
