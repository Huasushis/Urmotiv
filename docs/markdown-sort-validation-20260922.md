# Markdown 编辑与题号排序

- 带语言名的代码块使用语法高亮，未指定或未知语言保持原文。不执行代码中的 HTML，代码内公式不被误渲染。
- 编辑框随文本伸缩，桌面与右侧预览对齐；图片加载、字体加载及宽度变化后更新高度，手机仍支持编辑/预览切换。
- 所有共用题目列表支持按题号数值升降序，包括超过 JavaScript 安全整数范围的编号；权限过滤在排序、分页之前完成。
- 历史署名来自私有原始表格，结合已核验的编号迁移记录、旧修订 UUID 和当前题名匹配。仅补入背景说明，不改基础审核内容、作者账号、状态或 AI 开关。具体数据迁移与备份记录保留在非 Git 运维交接中，不公开署名表。
