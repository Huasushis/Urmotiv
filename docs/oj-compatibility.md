# OJ 题目包兼容说明

本文只描述当前 Urmotiv 题目包适配器的公开支持范围。适配器是受信任插件，必须在 `/admin` 启用；任务创建时固定适配器编号和版本，Worker 执行前会再次校验，停用或版本变化会固定失败而不会换用另一份实现。

## 当前适配器

| 格式编号 | 适配器版本 | 输入/输出 | 当前支持 |
| --- | --- | --- | --- |
| `hydro` | `0.2.0` | 单题或多题 ZIP 目录 | 每个直属题目目录独立导入 Hydro `problem.yaml`/题面/样例/评测配置/程序和公开资料；按损失报告导出 |
| `fps` | `0.1.0` | 单个原始 FPS XML | 导入一个或多个 `fps/item` 及当前交集字段；导出原始 XML，不再套 ZIP |

当前没有在公开传输目录注册其他 OJ 格式，也不能把通用 ZIP 自动当作某个 OJ 格式。`formatId` 必须取已启用适配器目录返回的编号。

## Hydro

依据 Hydro 公布的题目导入/下载目录约定，适配器识别：

```text
<题目目录>/
  problem.yaml
  problem.md 或 problem_语言.md
  solution/*.md
  testdata/config.yaml
  additional_file/
  std/
```

ZIP 根目录本身可以是一个题目目录，也可以包含多个这样的直属子目录；后一种形式会逐目录预览并一次创建多道题。根题目与子目录题目混放、或根部文件无法归属到具体题目时会拒绝导入。

`problem.yaml` 至少要有 `title`。`testdata/config.yaml` 中的时间、内存、数据点、子任务、判断程序和交互程序映射到 Urmotiv 评测配置；普通题缺输出文件、交互题缺交互程序、提交答案题缺自定义判断程序时拒绝导入。多份语言题面必须在预览时明确选择。

Hydro 的 `Background`、`Description`、`Format`、`Samples`、`Limitation` 和 `Hint` 一级 Markdown 分区被识别；未知分区保留在基础题面并提示。Hydro 无法表达的本站难度会成为 warning，不会静默换算；内部附件没有 Hydro 对等的可见范围，相关导出会被阻止。

本插件是独立实现，只根据公开格式行为转换，不复制 Hydro 源码、题目、测试数据或资源。Hydro 代码仓库标注 AGPL-3.0-only；若你另行复制、修改或分发 Hydro 代码，应遵守其许可证。格式细节以 [Hydro 官方文档](https://docs.hydro.ac/docs/Hydro/user/problem-format)和上游仓库为准。

## FPS XML

FPS 适配器接收未解压、严格 UTF-8 的单个 XML，固定以安全相对路径 `problem.xml` 提供给插件。输入必须有至少一个 `fps/item`，多个 `item` 按出现顺序全部导入；拒绝 `DOCTYPE`/`ENTITY`、未知元素/属性、重复必填元素、危险名称、非正数限制值、样例输入输出数量不一致或测试文件无法配对。

当前交集包含题名、时间/内存、题面、样例、测试输入输出、解答程序、前后置程序、特殊判断、交互程序、答案判断程序和内嵌图片。FPS 没有标签、难度、子任务、依赖或计分结构，导入不会编造这些值；不能无损表达的字段进入来源扩展或损失报告。

FPS 导出仍是单个 XML。内部附件会阻止导出；特殊判断、交互、提交答案或标准程序只有在原包保存相应程序正文时才允许导出。适配器是独立实现，依据 [freeproblemset 公共仓库](https://github.com/zhblue/freeproblemset)的公开 DTD 和文档；上游标注 LGPL-3.0，复制/修改上游实现时请遵守其许可证。

## 共同安全边界

- 核心在插件接触内容前检查归档路径、符号链接、重复名、压缩比、条目数、单文件/总量上限和 XML 外部实体；插件不能自行解压、执行程序或访问外网。
- 导入预览不写数据库；确认后任务按题独立事务写入。冲突只能明确选择 `create` 或有权限的 `update`。
- 导出前返回 error/warning/info 丢失报告；内部附件、权限、访问记录、审核意见、比赛信息、令牌和插件私有设置默认不导出。
- 失败响应、审计和任务报告只保存固定错误编号、格式编号/版本、计数和必要的相对位置，不保存题面、题解、测试数据、程序正文或上游原始错误。
- 任务和下载都重复进行权限检查；调用者不能通过题号、文件名、列表计数或 `404` 差异探测无权题目。

更多字段映射与任务行为见[题目包参考](problem-package.md)，插件接口见[插件开发指南](plugin-development.md)。
