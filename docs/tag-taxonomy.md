# 知识点目录与管理规格

- 版本：0.1 草案
- 日期：2026-08-02
- 状态：用户提供的初始目录已完整登记；标为“待确认”的名称在确认前不得擅自合并或删除

本文规定题目知识点的目录、选择、导入和管理行为。目录以用户提供的清单为主体；Hydro 官方目录只用于核对常见术语和参考“两层折叠”的交互，不直接复制，也不把 Hydro 的自由输入标签模型带入 Urmotiv。

## 1. 产品规则

- 知识点采用“分类—标签”两层目录。分类只用于折叠、排序和查找，不能直接选中；题目选择分类下的标签。
- 普通用户只能从当前启用的目录中选择，不能临时输入新标签。拥有 `tag.manage` 的真人管理员可以新增、重命名、移动、排序、停用、恢复和删除目录项。
- 一道题必须有至少一个、最多三十个知识点标签；同一标签不能重复。一个标签可以被多道题使用。
- 标签和分类使用不会随显示名称变化的稳定编号。重命名不能改变编号；旧名称可以保存为导入别名，但别名不能在页面中作为另一枚可选标签出现。
- 显示名称在同一分类内按标准化结果唯一。标准化至少忽略首尾空白和无意义的大小写、全半角差异；疑似同义词由管理员确认，程序不能仅凭字符串相似度自动合并。
- 目录有单调递增的全局版本号。管理页面的修改请求必须携带读取时的版本；版本已经变化时返回冲突并要求重新预览，不能覆盖他人的修改。
- 所有目录管理操作都写入不可修改的审计记录。审计和错误信息不得包含私有题目的编号、标题、题面、题解、附件名或知识点之外的内容。
- 机器人账号固定禁止 `tag.manage`，角色、单独授权和插件都不能解除。

## 3. 名称规范化与待确认项

初始导入必须保留上节原词。下列内容只是管理员确认清单，不是自动迁移规则：

| 原词或现象 | 建议显示方式或需要确认的问题 |
| --- | --- |
| `双向bfs`、`ST表`、`Sg 函数`、`gcd`、`bitset`、`wqs二分` | 可分别统一为“双向 BFS”“ST 表”“SG 函数”“GCD”“bitset”“WQS 二分”；先确认协会习惯 |
| `动态规划基础 (DP)`、`动态树 (LCT)` | 可统一中文括号及空格，但稳定编号不变，原写法保留为导入别名 |
| `K-DTree` | 需确认采用“K-D Tree”还是“KD 树” |
| `Polya 原理` | 需确认采用“Pólya 定理/原理”中的哪种显示方式；搜索别名可以保留无重音写法 |
| `深搜/宽搜` | 需确认保留组合标签，还是拆成“深度优先搜索”和“广度优先搜索”两枚标签 |
| `暴力/枚举`、`堆/优先队列`、`二叉搜索树/平衡树`、`单调栈/单调队列`、`差分/前缀和`、`概率/期望`、`折半搜索/中途相遇法` | 需逐项确认是同义显示还是两个可独立选择的知识点；不得按斜杠自动拆分 |
| `图` 与 `图论`、分类名与同名标签（如“数学”“组合数学”“博弈论”） | 宽泛标签可能有意表示综合题，不能因名称宽泛而删除；需确认适用边界和帮助文字 |
| `主席树`、`ODT` | 可保留常用俗名，但建议增加正式术语作为搜索别名或帮助说明 |
| `序计数`、`矩阵优化`、`FMT`、`turtle`、`选择题`、`通信`、`二进制` | 含义或分类边界待用户/管理员确认；确认前原样保留并在管理页提示，不擅自猜测 |

管理界面应支持搜索别名和查看帮助说明。别名只帮助匹配导入文本和搜索，不能绕过停用状态，也不能让两个稳定编号自动合并。
别名只关联可选择的叶子标签，不关联分类；标签停用后可以保留或补充旧名称别名，用于解释历史记录和人工映射，但不能因此恢复为可选状态。

## 5. 选择与页面行为

- 编辑器按分类显示可折叠的标签列表；默认展开包含当前选择或搜索结果的分类。桌面和手机都要能清楚看到已选标签并单独移除。
- 搜索同时匹配当前名称、管理员确认的别名和帮助说明；结果仍显示所属分类。
- 已停用标签不出现在新选择列表中。旧修订、审核意见或其他历史记录引用它时显示原名称和“已停用”，不能显示成未知编号。
- 普通保存、审核建议写回和导入执行都必须在服务端确认标签存在、启用且是可选标签；页面隐藏选项不能代替权限与有效性检查。
- 题目同时拥有多枚标签时，显示、筛选和导出均按集合处理，顺序不表达主要与次要关系。需要主知识点时应另行设计字段，不能偷用数组顺序。
- 管理入口位于后台设置。仅拥有 `tag.manage` 的真人账号看到并能调用；其他人即使直接请求接口也返回 `403`。

## 6. 导入和历史迁移

- 原生包应保存稳定标签编号以及必要的显示名称。导入到另一站点时先按受信任编号、管理员确认的别名或人工映射查找，不能只按模糊字符串猜测。
- 外部包、表格或历史材料中的未知标签不得静默丢弃，也不得自动创建。预览必须逐项列出“已映射、待人工映射、明确忽略”及原因；存在未处理项时不能执行。
- 管理员可以在预览中选择已有标签，或先到目录管理页新增标签。选择“明确忽略”必须逐项确认并写入不含题目内容的迁移报告。
- 历史题目列表中由投题者自填的知识点只作为私有人工映射线索，不是正式目录映射，必须映射到当前目录并经人确认。自填难度不得进入题目候选、模型提示或 Fermata 准确性标定，也不得作为人工真值；难度必须由独立人工评定或可靠公开比赛结果提供。
- 历史审题意见可以不导入。未导入不能伪装成空白新意见，也不能从自填字段推造审核结论。

## 7. 停用与删除

页面可以使用用户熟悉的“删除”一词，但正常在线操作实际采用可恢复的停用，并同时处理当前题目，不能直接物理删除有历史引用的记录。

### 7.1 删除前预览

服务端先返回不泄露题目的汇总影响：当前修订正在使用该标签的题目数量、其中仅有这一枚标签的题目数量、历史修订引用数量、审核意见引用数量，以及分类包含的子标签数量。响应不能包含私有题目的编号、标题、作者、内容或链接。

预览返回目录版本和一次性确认标识。正式请求必须携带二者；版本、目标状态或影响数量变化时返回 `409` 并要求重新预览。

### 7.2 当前题目

- 对当前修订使用目标标签的每道题，系统在同一事务中创建一个新的管理修订，并从新修订的标签集合移除目标标签；不能原地修改已有修订或关联表。
- 题目还有其他标签时保留其余标签。目标标签是唯一标签时，管理员必须先选择一枚当前启用的替代标签；没有替代标签就拒绝整个操作，不能留下零标签题目。
- 替代标签已经存在于题目时只做去重，不产生重复关联。
- 管理修订不改变题目状态，也不重新开启已经结束的审核轮次；任何绑定旧修订的机器人领取、后台写入或并发修改必须按修订冲突规则失效或重试。
- 只要一题无法创建新修订，全部题目更新、标签停用和审计都回滚，不能出现只处理一部分的结果。

### 7.3 历史修订、审核意见和比赛快照

- 历史题目修订及其标签关联保持不变，内容摘要也保持不变。查看旧修订时把目标标签标为“已停用”。
- 已提交审核意见中的知识点引用作为当时意见保留并标为“已停用”，不能改写审题人的历史意见。
- 已组比赛固定的题目修订和导出快照保持原样，避免目录操作悄悄改变已经使用过的比赛内容。
- 恢复标签只让它重新可选，不把它自动加回后来产生的题目修订，也不改动比赛快照。

这同时满足“从已有题目的当前版本去除标签”和“修订、审核、比赛记录不可篡改”两项要求。

### 7.4 分类与物理删除

- 分类仍有子标签时不能删除或停用；管理员必须逐一移动或处理子标签，不能隐式级联。
- 硬删除只允许离线维护流程处理完全没有任何当前或历史引用、审核意见引用和审计依赖的目录项；它不是普通后台按钮。
- 在线停用完成后，标签稳定编号永久保留，不能分配给另一个含义。

### 7.5 事务、审计和目录版本

正式停用必须在一个数据库事务中锁定目录版本、目标标签和受影响题目的当前修订，重新计算影响，然后依次创建题目新修订、标记标签停用、递增目录版本并写审计。审计写入失败时全部回滚。

标签关联写入必须对标签行取得共享锁，标签停用、移动和类型或状态变更必须取得与之冲突的更新锁；分类与直属叶子也采用同一协议。这样普通题目可以并行选择同一标签，而停用标签或分类不能越过正在提交的引用写入。稳定编号和“分类/标签”类型一经创建不可在线修改。

审计只保存操作者稳定编号、目标标签稳定编号、修改前后目录版本、受影响数量、仅有一枚标签的数量、是否使用替代标签、替代标签稳定编号、时间和结果，不保存题目编号、标题、正文、意见正文或模型输出。

新增、重命名、移动、排序、恢复和别名修改也必须使用目录版本检查并写审计。重命名和移动不批量改写历史修订；页面按稳定编号解析当时或当前显示名称，若未来需要保留“当时名称”，应增加独立的目录名称历史，而不是复制题目内容。

## 8. 最低验收测试

1. 一道题可以保存多枚不同的启用标签，重复、零枚、超过三十枚、未知、已停用和分类编号均被服务端拒绝。
2. 普通用户能使用折叠目录选择标签，但不能新增自由文本或调用管理接口。
3. 拥有其他管理员角色的机器人仍不能管理标签；真人缺少 `tag.manage` 或有明确拒绝时同样失败。
4. 未知导入标签出现在预览中；未映射且未逐项明确忽略时执行失败，不能静默丢失或自动创建。
5. 删除多标签题目所用标签后，当前修订只保留其余标签，旧修订和比赛快照不变。
6. 删除题目的唯一标签时必须提供启用的替代标签；失败时所有题目、目录版本和审计均无变化。
7. 并发修改目录或任一受影响题目后，旧预览的删除请求返回冲突，不做部分更新。
8. 停用标签仍能在历史修订和旧意见中以“已停用”显示，恢复后不会自动加回当前题目。
9. 分类有子标签时不能删除；任何操作都不能隐式级联或复用旧稳定编号。
10. 管理审计和错误响应只含允许的固定元数据，不泄露受影响私有题目及其数量之外的信息。
