# 节奏短句

Urmotiv 的标志由四个长短相间的形状组成，借音乐动机的重复与变化，表达想法在协作推敲中成为题目、编排为比赛的过程。深青色 `#0b4554` 与亮青色 `#10bad0` 交替出现；小尺寸使用纯色，避免渐变和细线丢失。

最终标志位于 `apps/web/public/brand/urmotiv.svg`；仓库封面源文件是 `docs/assets/cover.svg`，预览是 `docs/assets/social-preview.png`。网站使用可缩放的 SVG，不依赖图片服务。

构思阶段使用 imagegen CLI 的 `gpt-image-2.5-sunburst` 从零探索；用户选择“01 节奏短句”后，使用 `gpt-image-2.5-flare` 精修，最后人工整理成上述矢量路径。精修提示词核心：提取选定的四元素节奏，保留长短与方向变化，深青与亮青交替，纯白底，不要字母、书本、音符图标、数字、文字或渐变。封面为矢量排版，不是产品截图。
