## 性能证据

更新前同一临时会话的服务器本机请求：session 首次 49ms、后续 3–6ms；题库首页 18–52ms；本人资料与用户目录 4–6ms。公网相同接口约 400–1300ms，说明当前主要等待在网络，不能宣称数据库瓶颈。

首屏 JavaScript 从约 1129 kB / gzip 322.7 kB 降到 471 kB / gzip 139.5 kB。较重的 Markdown/数学编辑器和后台页面按需加载；导航壳仍保留，加载失败提供刷新入口。账号安全与关联身份的请求在资料页同时启动，服务端权限检查不变。

生产更新前，在两个独立空缓存浏览器环境测得：题库可操作约 5145ms，个人资料约 3946ms。公网时间易受网络波动影响，单次数字不代表稳定上限。

更新后首次公网测量分别为 8611ms / 18647ms，第二次为 4786ms / 5157ms；服务器接口依然为几至几十毫秒（题库一次 104ms）。第二次请求瀑布显示 HTML 起始等待约 1.4–2.4 秒、会话及数据请求约 0.6–1 秒；资料页的三个请求确实同时启动。实际首屏脚本传输从约 331 kB 减为 144–150 kB。确认减少传输与串行等待，但未声称公网加载时间稳定改善，网络波动仍占主要部分。
