# 比赛整包导出验收

比赛详情提供「导出比赛题目包」，复用题目包预览、后台任务和下载流程。服务器从方案读取全部固定版本，拒绝缺题、换序和过期方案；比赛权限不会代替每道题与数据文件的权限。

- 题目包 API 完整文件 50 项及数据库比赛 2 项通过；增加顺序目录的路径跳转、重名和容量反例后，比赛导出 3 项与比赛服务 6 项再次通过。
- 真实数据库、对象存储和后台任务验证两题 Hydro 整包：题库修改后仍保留比赛旧题名、旧题面和数据，下载包可直接重新导入；FPS 整包按顺序包含两个 XML。
- 比赛不存在与无权请求均 404；撤销比赛导出权限后，排队任务失败，已完成任务、重放和下载不可访问。只有导出权限的账号不能修改方案。
- 后台题目包处理器 36 项通过。比赛来源元数据仅用于宿主授权和打包，不传入格式插件的业务选项。
- 桌面、手机浏览器检查全题固定版本请求、仅启用格式、下载入口、方案变化提示和无横向溢出。此页面测试使用合成接口，实际包字节与重新导入由上述真实 API 测试验证。
- Web 全量 24 文件 154 项通过；API/Web/后台任务类型检查与 Web 构建通过。

所有测试限制单个 worker。本批没有数据库迁移，也不改变任何题目的审核状态或 AI 审题开关。生产验证结果在部署后补充。

生产首次导出发现已有进度计算缺陷：11 题时第一题转换把进度提升到 10%，第二题读取又写入 6%，数据库的单调进度约束拒绝更新，任务因此失败。逐题只读诊断确认全部题目都能完成格式转换，问题不在历史题内容。读取阶段改用与转换阶段一致的 10% 下限，补真实数据库 11 题整包回归；不删除进度约束，也不靠放宽数据库规则绕过。
