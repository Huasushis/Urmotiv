# 密码与邮箱操作验收

范围：本人修改密码、邮件找回、验证后更换主要邮箱、旧会话与一次性凭证失效。统一身份主动绑定/解绑仍未实现，本批不宣称完成。

- API 7 文件 29 项回归通过：账号安全、真实 PGlite 数据库事务、登录安全、SMTP 投递、注册用户名、个人资料和 root 恢复数据库。
- 增加 root 本地改密、恢复链接重发与过期验证后，账号安全 8 项通过。
- 数据库测试覆盖一次性消费并发、用途隔离、认证版本变化、邮箱唯一冲突、旧会话失效、用户名保持、审计原子性及审计失败回滚。新迁移 0028 只增加账号操作令牌表，不改旧用户或题目。
- 会话建立前复查密码散列和认证版本：旧密码/旧邮箱的登录请求不能跨凭据变更继续创建新会话。用户名登录测试改用真实已注册/已验证凭据，保持大小写与错误一致性验证。
- Web 全量 24 文件 154 项通过。
- 桌面、手机各跑通同一合成账号：原密码登录 → 修改密码 → 新密码登录 → 发起换邮箱 → 新邮箱链接确认 → 旧邮箱通知 → 找回密码 → 恢复链接设密 → 新邮箱/新密码登录，用户名与账号身份保持。浏览器经过真实 Fastify 路由，投递为仅测试可读的内存邮箱，没有公开取票接口，也不调用真实用户邮箱。
- 视觉检查发现桌面表单误继承两列布局，已将各安全表单改为单列、外层双栏；手机单栏。修复后两种尺寸完整流程再次通过，个人资料和重设密码截图已检查。
