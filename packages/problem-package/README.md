# 题目包基础

这个工作区定义 Urmotiv 的原生题目包，以及其他 OJ 格式转换器要实现的共同接口。原生包是 ZIP，里面保存题面、题解、样例、
测试数据、评测配置和附件；每个文件都有 SHA-256 校验值，用来发现传输或存储后的改动。其他格式也可以使用一个未经压缩的
原始 XML 文件，但必须通过 `readProblemPackageInput` 按文件名和文件开头共同检查，并在适配器中明确声明 `single_file`。

这里不直接把 ZIP 解压到磁盘。后台任务应先从 ZIP 的目录记录读取文件名、类型、压缩前后大小，调用
`validateArchiveMetadata` 拒绝路径跳转、符号链接、设备文件、重复路径、过深目录、超限文件和异常压缩比例；随后才按大小限制
读取文件字节，再调用 `createSafeArchive`。这样文件在通过检查前不会触及工作目录。

`urmotivNativeAdapter` 先校验 `checksums.sha256`，再读取 YAML 清单和 Markdown。导出时它返回安全的相对文件列表，
由后台任务在隔离目录中再次检查并写成 ZIP。格式转换器只能转换已获授权的题目；创建任务、读取文件和发放下载地址时的权限检查由
API 与后台任务完成，不在这个包中绕过。

丢失信息报告中的 `error` 表示不能导出，`choice` 表示用户还要选择处理方式，`warning` 表示会按用户选择省略内容，`info`
只是提示。任何目标格式不能保存的内容都应进入报告，不能被静默舍弃。
