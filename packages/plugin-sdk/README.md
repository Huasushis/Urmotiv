# 插件开发包

这个工作区提供插件向 Urmotiv 注册提交前检查、审核规则、审核条目类型和题目包格式转换器的接口。注册完成后必须调用
`registry.lock()`；之后不能再替换处理函数。

提交前检查只能返回“继续”或“阻止”，不能直接修改题目状态、所有者或权限。检查按管理员给出的顺序运行，只要有一个检查阻止，
提交就停止。检查超时、抛错或返回不符合结构的数据时，按该检查的 `failureBehavior` 决定阻止或继续；用户主动取消永远会停止提交。

审核规则只能使用当前轮次、仍有审核权限的意见。开发包会检查规则返回的意见编号，防止它引用旧意见或未声明支持的审核条目。
核心服务仍会在写入最终状态前重新检查权限和题目状态。

插件不通过这个包取得数据库连接、密钥、Cookie 或其他插件的设置。格式转换器拿到的是已经通过文件安全检查的 `SafeArchive`，
它也不负责给用户授权或跳过导入、导出任务中的权限检查。
