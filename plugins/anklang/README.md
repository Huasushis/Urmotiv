# Anklang 接入插件

这个插件在用户提交题目前调用独立运行的 Anklang 服务，显示可能相似的公开题目。它只负责连接和校验结果，
不把 Anklang 的公开题库复制到 Urmotiv，也不会让远端建议直接取得审核通过权限。

## 发送的信息

插件发送题目名称、类型、知识点、基础题面和题目内容摘要。它不发送作者、邮箱、学号、基础题解、完整题解、
测试数据、附件、审核意见或 Urmotiv 权限。服务令牌由 Urmotiv 的密钥存储提供，不写入普通插件设置。

接口为 `POST /api/v1/checks/similarity`，请求和响应都带 `apiVersion: "1"`。响应必须返回同一个内容摘要；
否则插件会把结果视为过期或串题并拒绝使用。响应正文最多 2 MB。

## 缓存

宿主程序可以提供 `AnklangCache`，用题目内容摘要读取和保存结果。只要名称、类型、知识点或基础题面改变，
核心程序就应生成新的摘要，因此旧结果不会套到新内容上。缓存到期时间由 `cacheMinutes` 设置。

## 提交行为

- `failureBehavior=block`：服务超时、不可用或返回格式错误时不提交题目，适合强制查重。
- `failureBehavior=continue`：服务失败时继续提交，由宿主记录失败状态，适合试运行。
- `blockWhenRecommended=true`：Anklang 明确建议先处理相似题时阻止提交，并只返回候选数量、最高相似度和说明。

远端建议只是一次提交前检查。核心权限、必填字段、冻结规则和最终审核规则仍由 Urmotiv 判断。
