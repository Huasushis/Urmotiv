仓库中的 `fps.current.dtd`，固定提交
[`7782b3815fd40f5bba95b5d7b90e3fbefafae656`](https://github.com/zhblue/freeproblemset/commit/7782b3815fd40f5bba95b5d7b90e3fbefafae656)

上游仓库根 `LICENSE` 标为 **LGPL-3.0**，上游 README 对“准确兼容”和衍生格式另有说明。
本插件没有复制上游的源代码、题目、测试数据、题解、程序或资源文件，只根据公开的格式定义
编写独立实现。使用者如计划复制、修改或分发 FPS 格式本身，应自行遵守上游许可证。

「支持」只表示格式转换能力，不表示有权复制、公开或再分发包内题面、题解、测试数据、程序和附件。
上游仓库公开放置的示例题目仍需要逐项确认其题面、数据、题解和第三方素材的许可，不能从
“仓库公开”推断可再分发。本项目测试夹具全部为独立人工构造的最小合成内容，且不含任何真实 OJ
题目材料。
