# 默认审核人数规则

这个内置插件根据当前审核轮次中的有效意见给出“继续等待”“通过”或“不通过”。它不会修改题目、权限或审核意见，
最终状态仍由 Urmotiv 核心服务在重新检查权限后写入。

默认设置需要两份通过意见，允许零份不通过意见。也就是说，只要出现一份有效的不通过意见，规则就给出不通过；
没有达到通过人数时继续等待。“需要修改”意见不算通过或不通过，因此会让题目保持待审核。

机器人意见默认不计数。组长明确开启“计算机器人意见”后，插件才会计算仍有审核权限的机器人意见。旧审核轮次、
已经失去审核权限的人以及同一审题人的旧版本意见都不会计入。

核心提供的意见快照还包含 CF 难度、质量、思维难度、代码难度、建议知识点编号和主要改进点，但这条默认规则不会
用这些字段偷偷改变结果，只读取结论和“是否计算机器人意见”的设置。“需要修改”仍然既不算通过也不算不通过。
如需按这些结构化字段设置门槛，应安装或编写另一条审核规则，并在管理页选择它；仅审题人可见备注和题目内容不会
提供给任何审核决定规则。

插件不读取数据库、文件、密钥或网络服务，没有自己的数据表。停用或卸载后，已有审核意见仍保留，只是系统需要改用
其他审核规则或由有最终决定权的人处理。
